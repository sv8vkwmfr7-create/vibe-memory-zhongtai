# 免费域名渠道调研

> 检索核实日期：2026-11-08 ｜ 用途：给 VibeMemory 四中台配一个**固定地址**（配合 Cloudflare 命名隧道，替代会过期的 trycloudflare 临时地址）
> 关键技术前提：想在 Cloudflare 免费版托管并把域名用于命名隧道，该域名必须是**公共后缀列表（PSL）**的成员后缀（这样 `xxx.后缀` 才算一个可注册域，CF 免费版才允许添加站点）。下表已按此标注。

## 二、对本项目的推荐路径

**目标：固定地址（如 `zhongtai.你的域名`）替代会过期的 trycloudflare 隧道。**

1. **主路线：DigitalPlat 注册 `xxx.us.kg` 或 `xxx.dpdns.org`**（门槛最低：只要 GitHub 账号，当天可得）→ 加入 Cloudflare 免费版 → 在 instabox（或腾讯云）上 `cloudflared tunnel login` 授权 → 创建命名隧道 `zhongtai` → 配置路由 `xxx.us.kg → http://localhost:8080`、`docs.xxx.us.kg → http://localhost:8081` → **大屏与全档各得一个永久固定地址**；
2. **平行保险：同时提交 eu.org 申请**（审核慢但永久免费，通过后作为备用域）；
3. **纪律提醒**：DigitalPlat 的续期窗口是到期前 120 天——错过域名即回收，建议拿到域名后在 Cloudflare 开启到期提醒或设日历。

## 三、风险与诚实声明

- 免费域名的本质风险：**审批/回收政策不由你控制**（eu.org 审核积压、us.kg 曾有 DNS 波动、DigitalPlat 规则可能变化）。重要生产用途建议成本价的 Cloudflare Registrar 域名兜底（¥70/年）；
- 免费二级域名的邮箱/身份核验环节可能变化，以注册当页提示为准；
- `trycloudflare` 临时隧道与免费域名方案可并存：拿到固定域名前不影响现有访问。
