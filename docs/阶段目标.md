# 数据中台 · 大阶段目标

> 设定日期：2026-11-09 ｜ 周期：3 个月（至 2027-02 上旬）

## 一句话目标

**建成「个人 AI 数据底座」——所有 AI 项目的数据都汇到这里；每个 AI 系统好不好，都用这里的数据说话。**

现在它只是「VibeMemory 的数据看板」；阶段结束时它是所有 AI 项目的中枢：数据进、质量出、每个系统变没变好一查便知。

## 验收标准（6 条）

1. **多项目接入**：至少 3 个项目的数据在里面跑（VibeMemory + 2 个新项目），新项目半天接完
2. **质量闭环**：任何接入的 AI 系统都能在这里被评测/测试/监控，「这周比上周好吗」自动出答案
3. **数据对外服务**：有 API 和公开页面，别的程序/别的机器能直接取数
4. **每份数据有身份证**：说明书（数据集卡）+ 版本 + 指纹 + 血缘，达到可对外公开标准
5. **全自动运转**：push 即采集、定时即产出、异常有信号，零手动运维
6. **数据量级**：从 402 条到万级以上资产记录，且有持续增长曲线

## 明确不做

分布式存储、多租户权限、实时流处理——等多人多项目压力真实出现再议。
